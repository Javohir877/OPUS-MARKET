Boshqaruv paneliga kirish

Panel o'zgarishlarni GitHub orqali saytga e'lon qiladi. Kirish uchun faqat shu do'kon repozitoriysiga ruxsatli GitHub kaliti (token) kerak.

Token qanday olinadi? (bir marta, 2 daqiqa)
  1. github.com → Fine-grained token yaratish sahifasini oching.
  2. Token name: OPUS admin, Expiration: masalan 90 kun.
  3. Repository access → Only select repositories → OPUS-MARKET.
  4. Permissions → Repository → Contents: Read and write.
  5. Generate token ni bosing va chiqqan kalitni shu yerga joylang.

Kalit faqat brauzeringizda saqlanadi va faqat api.github.com ga yuboriladi. Uni hech kimga bermang.
